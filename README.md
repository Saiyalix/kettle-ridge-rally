# Kettle Ridge Rally

An arcade rally game in the style of the classic Sega Rally games, with PS2-era graphics.
It runs in any modern browser: keyboard on a computer, touch controls on a phone.

**Play:** open the GitHub Pages link for this repository (Settings > Pages).

## Controls
- Keyboard: W/S or arrows for gas and brake, A/D to steer, Space for the handbrake, R to get back on the road, C for camera, Esc to pause.
- Phone: hold it sideways. Left thumb steers, right thumb has gas, brake and handbrake.

## Stages
- SS1 Kettle Ridge: forest roads, tarmac, gravel and snow
- SS2 Vulture Ledge: gravel and dirt along mountain cliffs
- SS3 Sakura Touge: Japan, torii tunnel, mountain pass and a neon town
